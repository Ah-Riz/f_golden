# v0.4 trade lifecycle

## State machine

`Assess → Authorized → Open → Protect → Manage → Closed → Evaluate`  
Any stage fail → `NoTrade` / WAIT. Critical unknown → WAIT.

## Entry stages (logged `SKIP_STAGE`)

1. Context — spread, session, spike, optional regime  
2. Bias — SMC LONG/SHORT; FLAT → WAIT  
3. Setup — sg_1 impulse + Dist break (legacy)  
4. Location — net R:R ≥ `InpMinNetRR`  
5. Trigger — optional closed-bar confirm (`InpEntryConfirmClose`)  
6. Execution — stops level, margin  
7. Risk — planned SL distance, % lots, episode remaining (real cash pre-send)  
8. Authorize → `OrderSend`

## Long rules (short = mirror)

- Bias bullish; impulse; Bid ≥ LineBuy; closed-bar confirm if enabled  
- SL: ATR_FLOOR or below confirmed swing low − buffer  
- TP: `TP_RR × risk`  
- Mode B: keep initial SL until profit ≥ `InpSLPlusActivateR`; then BE+lock / trail `InpTrailR` (tighten-only)  
- Thesis: if `InpThesisExit`, block pyramids when bias flips (no forced close)

## Exit priority

1. Broker hard SL/TP  
2. Equity DD kill (`FLAT reason=equity_kill`)  
3. Thesis block-adds  
4. Planned TP  
5. SL+/trail (`SL+` / `SL_MOD`)  
6. Dist/MinProfit flat (`FLAT reason=dist_tp`)

## Manage modes

| Mode | SL+ trail |
|---|---|
| A | Off — fixed / structural initial only |
| B | Delayed activate (default) |
| C | Structure trail after activate |
| D | Hybrid (experimental) |
