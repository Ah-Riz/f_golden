# v0.4 parameter reference

Units and defaults for `gold_rush_AI_v0.4.mq5`. Higher/lower effects are relative to the default pin.

| Name | Default | Unit | Range | Higher means | Notes |
|---|---|---|---|---|---|
| `InpManageMode` | 1 (B) | enum 0–3 | 0–3 | N/A | A fixed · B delayed SL+ · C struct trail · D hybrid |
| `InpStopMode` | 0 ATR_FLOOR | enum | 0–1 | N/A | 1 = STRUCT_ATR (confirmed swing ± buffer) |
| `InpStructBufferATR` | 0.25 | ATR mult | ≥0 | Wider struct SL | Mode A/C |
| `InpMaxStopDistance` | 50.0 | price | 0=off | More rejects | Reject if planned SL wider |
| `InpSLPlusActivateR` | 1.5 | R | >0 | Later SL+ | v0.3 was hard-coded 1.0 |
| `InpTrailR` | 1.0 | R | >0 | Wider trail | Mode B after activate |
| `InpEntryConfirmClose` | true | bool | — | Stricter | Closed bar 1 impulse |
| `InpMinNetRR` | 2.0 | ratio | >0 | Fewer trades | After spread estimate |
| `InpThesisExit` | false | bool | — | Blocks pyramids on bias flip | No market-close |
| `InpAllowDistFlat` | true | bool | — | Dist+MinProfit basket flat | `false` demotes Dist for ManageMode B/C/D only (Exp A) |
| `InpAllowNewsWiden` | false | bool | — | Can loosen SL | Default OFF in v0.4 |
| `Step` | 20 | pipfactor | — | Larger pyramid spacing | Now uses `Id_046F8` like Dist |
| `UseSLPlus` | true | bool | — | Enable protect path | Mode A ignores trail |
| `SLPlus_LockPoints` | 10 | `_Point` | — | BE lock offset | After activate |
| `TP_RR` | 2.5 | R | — | Farther TP | Unchanged |
| `InpRiskPctEquity` | 1.0 | % | — | Larger size | Unchanged pin |
| `MaxEquityDDPercent` | 5.0 | % | — | Earlier kill | Unchanged |

Reuse Dist/MinProfit/ATR_* / RiskPoints / SMC / regime / news from v0.3. Prefer ablation sets over expanding this surface.
